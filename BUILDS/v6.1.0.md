### 3. Skill Management via Chat (4 new tools)

| Tool | What it does |
|---|---|
| `createSkill(name, description, trigger, instructions)` | Creates a new skill .md file in user storage |
| `deleteSkill(name)` | Deletes a user-created skill |
| `getSkill(name)` | Returns the full instructions of a skill |
| `sendAttachmentTo(package, filename, caption?)` | Improved — now accepts optional caption parameter |

### 4. UI Changes

- ✅ Removed Tamil/English language toggle button (langBtn)
- ✅ Removed old voice input button (voiceBtn)
- ✅ Added Google Voice button (uses `RecognizerIntent.ACTION_RECOGNIZE_SPEECH`)
- ✅ Tap floating overlay button to stop AI speaking (if TTS is active)

### 5. App Open/Close Detection

Accessibility service now fires broadcasts when apps open/close:
- `com.ai.agent.APP_OPENED` with `package_name` extra
- `com.ai.agent.APP_CLOSED` with `package_name` extra
These trigger `app_opened` and `app_closed` rules.
