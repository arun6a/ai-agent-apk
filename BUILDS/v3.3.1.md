## What Changed

### Bug Fix: Gemini returned HTML instead of JSON

**Symptom**: When using Gemini provider, app showed:
```
Error: Value <!doctype of type java.lang.String cannot be converted to JSONObject
```

**Root Cause**: `LLMClient.chat()` was POSTing to just the base URL:
```
https://generativelanguage.googleapis.com/v1beta
```

But Gemini requires the full API path with model + API key:
```
https://generativelanguage.googleapis.com/v1beta/models/gemini-2.0-flash:generateContent?key=YOUR_KEY
```

**Fix**: Added URL construction for Gemini in `LLMClient.kt`:
```kotlin
val finalUrl = if (provider.id == "gemini") {
    "$endpoint/models/$model:generateContent?key=$apiKey"
} else {
    endpoint
}
```

The test connection in `AIProviderSettingsActivity.kt` already had this correct — only the main `chat()` path was broken.
