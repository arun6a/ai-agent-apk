# v2.4.0

**Released:** 2026-10-07
**versionCode:** 61
**Commit:** bf94758

## What's New

### New AI providers (in Settings → AI Provider)
- **Groq (Ultra Fast)** — `llama-3.3-70b-versatile`, `llama-3.2-11b-vision-preview`, `mixtral-8x7b-32768`. 30 req/min, 14400/day free.
- **Together AI** — `meta-llama/Llama-3.3-70B-Instruct-Turbo`, `meta-llama/Meta-Llama-3.1-405B-Instruct-Turbo`, `Qwen/Qwen2.5-72B-Instruct-Turbo`. $5 free credit on signup.
- OpenRouter models list now includes free **vision-capable** models:
  - `google/gemma-4-31b-it:free` (vision!)
  - `nvidia/nemotron-3-nano-omni-30b-a3b-reasoning:free` (vision + audio)

### Multi-provider VLM (vision)
- `ToolExecutor.analyzeScreenWithVLM()` now routes to the user's configured provider when it has a vision-capable model, instead of always using the Z.ai proxy
- Added `isVisionCapableModel(providerId, model)` heuristic — checks model name patterns (gemma-4, nemotron-omni, llava, *-vision*, *-vl*)
- Falls back to sandbox `/api/llm/vision` when provider isn't vision-capable (e.g., Z.ai proxy, custom non-vision models)

### Smarter agent brain
- **`launchApp` now returns FULL screen text** (up to 3000 chars, was 200) — LLM can see actual UI elements (button labels, content descriptions, menu items) and decide what to click
- **Wait increased** from 2s → 2.5s (slow-loading apps like WhatsApp need more time)
- **System prompt rewritten** with app-specific UI tips:
  - WhatsApp: search is a magnifying glass ICON at top-right (~970, 200) — NOT a "Search" text button. Do not use `clickByText("Search")` on WhatsApp's main screen.
  - YouTube: same — search icon at top-right (~970, 180)
  - General rule: if `clickByText("Search")` fails twice → switch to VLM (`findElement` + `tap(x, y)`)

### LLMClient auth handling
- Added `groq` and `together` to the `when (provider.id)` auth header block — both use OpenAI-compatible Bearer token auth, no extra headers needed

## Known Issues
- Gemini's multimodal format is different from OpenAI — Gemini vision falls back to Z.ai proxy (TODO: native Gemini vision support)
- VLM-based search-icon detection depends on the model's quality — Gemma 4 31B works but is slower than text-based readScreen
- The "8-step limit" the user reported in WhatsApp testing was actually the `MAX_REPEATED_TOOLS=3` infinite-loop guard kicking in (3 retries of `clickByText("Search")`) — now the system prompt tells the LLM to switch to VLM after 2 failures

## Migration Notes
- Existing users (on v2.3.1 or earlier) need to update their AI Provider settings — the new providers (Groq, Together) appear in the dropdown after installing v2.4.0
- SharedPreferences keys are unchanged — existing Z.ai/OpenRouter/Gemini/Custom configs persist
