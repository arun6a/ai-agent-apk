## What Changed

### NEW: 15 Activity Tools

Tools to open specific screens inside other apps using Android Intents:

| Tool | Purpose | Example |
|------|---------|---------|
| `openActivity(package, activity)` | Open any activity by class name | `openActivity("com.whatsapp","com.whatsapp.HomeActivity")` |
| `openDeepLink(uri, package?)` | Open deep links | `openDeepLink("spotify:search:cats")` |
| `openAppWithData(package, uri, action?, mimeType?)` | Open app with specific data URI | `openAppWithData("com.android.chrome","https://...")` |
| `searchInApp(package, query)` | Search within YouTube/Spotify/Instagram/Chrome | `searchInApp("com.spotify.music","lofi")` |
| `listAppActivities(package)` | List all activities in any app | `listAppActivities("com.whatsapp")` |
| `openWhatsAppChat(phone, message?)` | Open WhatsApp chat directly | `openWhatsAppChat("+919001234567","Hi!")` |
| `openYouTubeVideo(videoId)` | Open specific YouTube video | `openYouTubeVideo("dQw4w9WgXcQ")` |
| `openMapsLocation(query, lat?, lng?)` | Open Google Maps | `openMapsLocation("Chennai")` |
| `composeEmail(to, subject, body)` | Open Gmail composer | `composeEmail("user@gmail.com","Hello","Body")` |
| `playSpotify(query)` | Search and play on Spotify | `playSpotify("Shape of You")` |
| `openInstagramProfile(username)` | Open Instagram profile | `openInstagramProfile("nasa")` |
| `openTelegramChat(username)` | Open Telegram chat | `openTelegramChat("durov")` |
| `makePhoneCall(number)` | Make phone call | `makePhoneCall("+919001234567")` |
| `openGoogleSearch(query)` | Open Google search | `openGoogleSearch("weather today")` |
| `openAppSettings(package)` | Open app's Android settings | `openAppSettings("com.whatsapp")` |
| `shareToApp(package, text)` | Share text to specific app | `shareToApp("com.whatsapp","Hello!")` |

### NEW: Foreground Package Tracking

Added `getCurrentForegroundPackage()` to `AgentAccessibilityService.kt`:
- Tracks which app is in the foreground via `onAccessibilityEvent()`
- Also checks `rootInActiveWindow.packageName` (most reliable)
- Used by `openActivity` and `openAppWithData` to verify the app actually opened

### Updated: System Prompt

Added two new sections:
1. **"App Activity Tools"** — documents all 15 new tools
2. **"App-Specific Quick Tools"** — documents app-specific shortcuts (WhatsApp, YouTube, etc.)

Updated **"Common App Packages"** section with known activity class names for major apps.

## Impact

### Before (v3.3.2): "Open YouTube and search cats"
```
1. launchApp(youtube)           → wait 2.5s, read screen
2. findElement("search icon")   → VLM call to find icon
3. tap(x, y)                    → tap the search icon
4. readScreen                   → verify search box opened
5. type("cats")                 → type search query
6. submitInput()                → press enter
7. readScreen                   → verify results
= 7 API calls, ~45K tokens
```

### After (v3.4.0): "Open YouTube and search cats"
```
1. searchInApp("com.google.android.youtube", "cats")
= 1 API call, ~5K tokens
```

**Savings: 86% fewer calls, 89% fewer tokens!**

## Known Issues

- Some apps may not support deep links (falls back to launching main activity)
- `listAppActivities` shows internal (non-exported) activities — can't open those
- `makePhoneCall` requires CALL_PHONE runtime permission (auto-falls back to dialer if not granted)
