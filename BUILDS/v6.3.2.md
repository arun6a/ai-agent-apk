## What's New (v6.3.0 → v6.3.2)

### 1. Dynamic System Prompt System (v6.3.0)

**5 prompt modes** user can select in Settings:

| Mode | Tokens | Daily Calls (Groq) | Description |
|---|---|---|---|
| 🧠 Smart (DEFAULT) | ~11,000 | ~34 | Full prompt — all tools, tips, examples, workflows |
| 🤖 Dynamic | ~800-4,000 | ~150-300 | Auto-selects relevant tools per task (keyword matching) |
| ⚖️ Balanced | ~1,500 | ~250 | Trimmed — core tools + key rules + shortcuts |
| ⚡ Fast | ~750 | ~500 | Minimal — tool names + 8 rules only |
| 📝 Custom | User-defined | Varies | User-edited prompt from storage |

**Files:**
- `system_prompt_smart.txt` (47KB) — full prompt (renamed from system_prompt.txt)
- `system_prompt_balanced.txt` (6KB) — trimmed version
- `system_prompt_fast.txt` (3KB) — minimal version
- `/storage/.../system_prompt_custom.txt` — user-edited (created on demand)

**DynamicPromptBuilder.kt** — analyzes user message keywords, selects relevant tool categories:
- 17 tool categories with keyword matching (Screen, Apps, Shortcuts, Browser, Web, Memory, Knowledge, Files, Rules, Contacts, Calendar, Device, Media, Vision, Notification, Skills, Async, Terminal)
- 4 app-specific tips (YouTube, WhatsApp, Instagram, Spotify)
- Falls back to shortcuts + device + memory if no keyword match

### 2. Fallback Mechanism (v6.3.1)

When dynamic mode is active and AI calls a tool NOT in the dynamic prompt:
1. Detects unknown tool calls on iteration 1
2. Auto-expands to full prompt (all tools)
3. Re-calls LLM with full prompt
4. Executes corrected tool calls
5. Logs: "AI called unknown tools: X — expanding to full prompt"

### 3. Browser vs Web Search Guidance (v6.3.1)

Added to CORE_PROMPT (always included in ALL modes):
```
## When to use WHAT (CRITICAL):
- RESEARCH (weather, news, find info) → webSearch + fetchPageText (BACKGROUND, no browser)
- INTERACTION (order, fill form, click) → browserOpen + browserClickText (VISIBLE browser)
- APP CONTROL (play YouTube) → searchInApp / launchApp (accessibility)
- SHORTCUT first → searchInApp, playSpotify, openWhatsAppChat before manual
```

### 4. Terminal Tool Added to Dynamic Prompt (v6.3.2)

`runShellCommand(command)` added to DynamicPromptBuilder with keywords:
- terminal, shell, command, run command, cmd, execute command, root, su

Also added to `system_prompt_fast.txt`.

### 5. Default Mode = Smart (v6.3.2)

Changed from `dynamic` to `smart` as default — user must manually enable dynamic mode.

### 6. ML Kit OCR Mention (v6.3.0)

All 3 prompt files now mention ML Kit:
```
readScreen is 3-tier: accessibility text → ML Kit OCR (free, offline) → VLM API (last resort)
```

### 7. Custom Prompt Edit/Restore

- **Edit Custom Prompt** button — opens text editor or dialog preview
- **Restore Original** button — deletes custom file, reverts to Smart
- Custom saved to: `/storage/.../system_prompt_custom.txt`
